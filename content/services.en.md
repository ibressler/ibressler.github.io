### Control and commissioning of custom and prototype machines

I develop and configure control systems for custom and prototype machines,
as well as for older equipment with outdated or missing controls. This
includes selecting and sizing the control and drive technology, configuring
axes and kinematics — including non-standard types of motion — and
commissioning the machine through to a ready-to-operate handover. Where the
mechanics are worth keeping but the control system is no longer
maintainable, I replace it with a current system (modernisation/retrofit).

This makes it possible to operate machines reliably even when no standard
control system is available, and to keep existing equipment in use rather
than replacing it.

**For:** workshops, university workshops, machine and special-purpose
machine builders, and operations with sound mechanics but an outdated
control system.

### Instrument integration and process data acquisition

I integrate production, test and measurement instruments into existing
software environments and automate the acquisition, storage and analysis
of measurement data. Instruments are connected via common interfaces such
as network, USB, serial connections, and others. This removes the need to
transfer readings by hand; the data is available in a structured,
consistent form and ready for immediate analysis.

This reduces sources of error, saves time and establishes the basis for
consistent digitalisation in laboratory and testing environments.

**For:** laboratories, research, development and testing teams, and small
manufacturers with test benches and measurement technology.

---

### Process and analysis software

I develop software that connects machine and measurement setups into
working processes: coordinate and geometry transformations, the generation
of machine-ready process and motion data, analysis and evaluation tools,
and interfaces between instruments and data storage. Implementation is
mostly in Python, and in C/C++ where required. Where it usefully extends
the process, a quality check can be added that performs an automated
target-actual comparison in a feedback loop, for example based on images
from camera data.

This produces reliable, traceable workflows and tailored tools wherever
standard software is not sufficient.

**For:** applications in which measurement technology, control systems and
data processing have to work together.

---

### Approach

For each task, I select suitable technologies and tools, adapt them to the
specific application, and develop the functions that are still missing.
Control technology, instrument integration and software therefore come from
a single point of contact, which reduces coordination effort and interface
losses between multiple service providers.

A project example:
For the prototype of a cylindrical ceramic 3D printer, I selected the
control hardware, configured the custom kinematics, calculated the print
data from the 3D model, and automated the quality inspection of the printed
result. Calculating the target data and checking the actual deviation were
thus part of a single, traceable process.

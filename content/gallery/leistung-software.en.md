I develop software that connects machine and measurement setups into
working processes: coordinate and geometry transformations, the generation
of machine-ready process and motion data, analysis and evaluation tools,
and interfaces between instruments and data storage. Implementation is
mostly in Python, and in C/C++ where required. Where it usefully extends
the process, a quality check can be added that performs an automated
target-actual comparison in a feedback loop — for example based on images
from camera data.

This produces reliable, traceable workflows and tailored tools wherever
standard software is not sufficient.

**For:** applications in which measurement technology, control systems and
data processing have to work together.
